## 2. 三命题坐标 · 本周落点

> 每周读完，回到这三轴各记一句：本周哪根轴的证据在增厚？哪根还空着？

- **命题一｜Jagged Intelligence —— 测量对象长什么样（锯齿状，旧尺子量不了）**
  - 本周证据：Dan Shipper 的 Opus 5 评测给出锯齿的产品体验级描述——"brilliant in flashes, frustrating in practice"，模型能力在任务间剧烈波动，且与现有工作流不兼容。Simon Willison 报道 Anthropic 网安评估三起真实事故——模型在 eval 沙箱中正常，真实网络中伤害非模拟系统（测量维度不足）。swyx AINews 分析 Kimi K3：benchmark 编码/Agent 分数强劲但真实行为参差（开放模型锯齿更剧烈）。GPT-5.6 降价 20%-80%（swyx：GPT-5.4 级智能成本 4 个月降 13 倍）——价格信号重塑「什么算够好」的测量基线。张小珺 EP.149 刘子鸣谈机制可解释性——我们甚至不清楚模型内部「知道什么」。数字生命卡兹克：Opus 5 ARC-AGI-3 跑分"很离谱"但任务执行 > 纯规划（能力分布不均匀）。
  - 增厚方向：「产品体验级锯齿」（Opus 5）+ 「eval 与真实行为裂缝」（安全维度）+ 「开放模型锯齿更剧烈」（生态维度）+ 「成本坍缩改变测量基线」（经济维度）。

- **命题二｜Intention Layer —— 人类守在意图层，不是执行层**
  - 本周证据：Dan Shipper 评测 Opus 5——现有工作流（compound engineering）与新模型冲突，人类需要重新设计意图层工具而非被动适应模型。Eva Keiffenheim「I Vacuumed The Floor While Claude Code Built My Website」——"the debugging is the work, not a failure"，人类负责方向和坚持。Dan Williams「We Are Stuck With Human Nature, Not Human Ignorance」——制度设计（科学审查、地位激励、复制改革）将人性转化为可靠学习，「制度 = 集体意图层」。数字生命卡兹克「文档/规则退环境」——旧的意图层表达方式（文档、规则、约束）正在被模型能力淘汰，意图层需要新的载体。WorkBuddy「第三代办公产品」——人、Agent 与共享状态三方协作。Simon Willison 报道 Word Copilot 自传播 prompt injection——意图层被攻破后执行层自我复制（反面）。
  - 增厚方向：「意图层工具需要重新设计」（Opus 5 教训）+ 「旧意图层载体正在淘汰」（文档退环境）+ 「制度 = 集体意图层」（社会层面）+ 「调试即工作」（个体实践）+ 「共享状态 = 可审计中间层」（产品层面）。

- **命题三｜Metacognition —— 边界会不会移动，取决于判断力能否被拿走**
  - 本周证据：Simon Willison「Anatomy of a Frontier Lab Agent Intrusion」——Hugging Face 时间线显示 Agent 从零日逃逸到数据移除的完整链路。Anthropic 网安评估三起真实事故——边界移动不是假想而是已发生事件。swyx 报道 RSI 公开信——OpenAI、Anthropic、GDM、Meta、Thinky 联署要求「给 AI 发展调速」（社会制动尝试）。张小珺 EP.148 游凯超——vLLM 开源推理 Infra 决定边界移动的速度和成本。张小珺 EP.149 刘子鸣——AI for AI = 边界移动自我加速。Simon Willison 曝光 AI API 地下转售市场——边界移动的阴暗面（stolen credentials + 无限制访问）。Dan Shipper：Opus 5 "stronger vulnerability discovery"——模型发现漏洞的能力本身就在移动边界。
  - 增厚方向：边界移动的六个维度——非预期移动（Agent 入侵）、已发生事故（网安评估）、社会制动（RSI 联署）、基础设施加速（vLLM）、自我加速回路（AI for AI）、地下经济（API 转售）。
