- **命题一｜Jagged Intelligence —— 测量对象长什么样（锯齿状，旧尺子量不了）**
  - 本周证据：Simon Willison 实测 Qwen 3.8 27B——图像框定、代码/工具调用与 agent 任务出色，但默认推理模式「wildly overthinking」，同一模型内部锯齿分明；Artificial Analysis 指数 52 分逼近旗舰模型，小开源模型重绘能力地图。swyx AINews：Z.ai CEO 唐杰谈 GLM 5.3 与「Death of Params」——参数量不再是测量标尺，新的 Post-training Scaling Law 接棒；Gemini 3.7 Flash 让 GDM 重回前沿。数字生命卡兹克同题跟进唐杰对 GLM-5.3 与 Scaling Law 的思考。Dan Williams 把问题推向极限：智能爆炸假说下，测量基线本身可能指数级移动。
  - 增厚方向：「参数量死亡，后训练接棒」（Death of Params + Post-training Scaling Law）+「小模型逼近旗舰」（Qwen 3.8 27B）——旧尺子（参数量、单一基准分）正在被成套替换，锯齿的形状从「模型之间」深入到「单个模型内部」（能力强项与过度思考并存）。

- **命题二｜Intention Layer —— 人类守在意图层，不是执行层**
  - 本周证据：swyx 报道 Matt Pocock「/wayfinder Skill」——把规划线程、调研、原型、工单组织成共享地图，直面 agent 项目「开局无法决定一切」的规划迷雾——规划成为意图层的新战场。Thorsten Ball #95 自述近期完全通过远程 agent 化环境完成工程工作——执行层整体让渡，人类退守意图层的第一手实录。Simon「Conceptual integrity and counting lines of code」——当 agent 产出质量有保障，代码行数反而成为约束，概念完整性是意图层要守的最后一块阵地；「Extensible Software in the age of LLMs」——LLM 写扩展 + 沙箱部署赋予用户超能力。数字生命卡兹克「AI 组织的 7 点心得」+「12 个常用 Prompt」——意图编码从个人技巧扩展到组织形态。硅谷101 E249——OpenClaw/Hermes 到本地自研 Agent 的演进与 A2A 网络。
  - 增厚方向：「规划迷雾成为意图层新战场」（/wayfinder）+「执行层完全 agent 化的第一手实录」（Thorsten 远程工作）+「概念完整性 = 意图层守土的最后阵地」（Simon）——意图层从「守住」进入「如何组织」的阶段。

- **命题三｜Metacognition —— 边界会不会移动，取决于判断力能否被拿走**
  - 本周证据：Eva Keiffenheim「How to Turn Information Into Knowledge」——让你感觉高效的信息消费习惯可能正在阻止大脑学习；有效学习需要知识有意义、可提取、可迁移、可持续——人类学习元认知的操作化。数字生命卡兹克「反常识的真相：Agent 如今在真实工作场景的成功率依然很低」——对 agent 能力的期望校准是元认知的基本功。Simon smolmachines 研究——用硬件级 VM（而非共享内核容器）沙箱化不可信 Python/JS：限制 CPU/RAM、断网、限文件——沙箱成为判断力边界的工程化身。Dan Williams 访谈智能爆炸——当研究时间线被压缩，人类元认知能否跟上系统能力，是 AI 控制问题的核心。
  - 增厚方向：「元认知双线分化」——人类侧：学习元认知（信息消费 ≠ 学习）；agent 侧：期望校准（真实成功率仍低）——加上「沙箱 = 边界的工程形态」（smolmachines），判断力的防线从观念层落到基础设施层。
